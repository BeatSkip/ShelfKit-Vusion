# libmf, the wtimer scheduler, the axradio engine and the ShelfKit layers

Sources: LibMF user manual (`vendor/LibMF-user-manual.txt`), headers in
`ShelfKit-Firmware/Shared/sdk/libmf/include/`, `Shared/firmware/axradio/`, `Shared/firmware/shelf*/`.

## libmf basics

- Prebuilt in `Shared/lib/libmf.lib` (SDCC archive). The duplicate debug labels in it were renamed (a patched build). **The build links the .lib; it does not compile `sdk/libmf/source`.** To change libmf, rebuild with `sdk/libmf/buildsdcc/Makefile` and replace the .lib.
- The header for this chip is `#include <ax8052f143.h>` (pulls in `ax8052.h`) plus `libmftypes.h`, `libmfradio.h`, `libmfwtimer.h`, `libmfflash.h`, `libmfuart0.h`, `libmfosc.h`, `libmfcrc.h`.
- `axcompiler.h` defines the portable keywords: `SFR`, `SFRX`, `SBIT`, `__reentrantb`, `__genericaddr`. In libmf, `__reentrantb ... __reentrant` marks functions that are reentrant, i.e. safe to call from an ISR.
- `libmftypes.h` has `#pragma callee_saves` for `wtimer_standby, enter_standby, enter_sleep, enter_deepsleep`, and `libmfradio.h` has it for `radio_read*/radio_write*`. Callers therefore don't save registers around these, and **a replacement for any of them must preserve R0-R7**.

## wtimer: the event scheduler

```c
struct wtimer_desc {                 /* MUST live in __xdata; field order fixed */
    struct wtimer_desc __xdata *next;
    wtimer_desc_handler_t handler;   /* void h(struct wtimer_desc __xdata *d) __reentrant */
    uint32_t time;                   /* absolute ticks, or relative before add */
};
struct wtimer_callback { struct wtimer_callback __xdata *next; wtimer_callback_handler_t handler; };
```

- `wtimer0_addrelative(&d)` / `wtimer0_addabsolute(&d)`: insert into the sorted queue. **Never add a descriptor that is already queued.** Call `wtimer_remove(&d)` first if in doubt.
- `wtimer_remove(&d)`, `wtimer0_remove`, `wtimer1_remove`: return 1 if the descriptor was found. The handler is not called.
- `wtimer_add_callback(&cb)` / `wtimer_remove_callback(&cb)`: queue a deferred call, typically from an ISR, to run in the main loop.
- `wtimer0_curtime()`: 32-bit tick count, wrapping. Compare times with signed differences: `(int32_t)(a - b) < 0`.
- Handlers are **not** run inside the interrupt. Expired descriptors move to a pending queue, and `wtimer_runcallbacks()` runs them from the main loop. Handlers therefore don't need to be ISR-safe, but they run late if the main loop is busy.
- wtimer0 = slow clock (512 Hz here), survives Sleep. wtimer1 = fast clock (FRCOSC/64 ≈ 312.5 kHz), **any pending wtimer1 event forbids Sleep**.
- Main loop shape (mandatory; `libmfwtimer.h` must be included in the file that defines `main`):

```c
for (;;) {
    wtimer_runcallbacks();
    flg = WTFLAG_CANSTANDBY;
    if (nothing_else_to_do && axradio_cansleep())
        flg |= WTFLAG_CANSLEEP;            /* or WTFLAG_CANSLEEPCONT */
    if (wtimer_idle(flg) == WTIDLE_SLEEP)
        reinit_peripherals();              /* sleep_cont came back */
}
```

- The vetoes linked into `wtimer_cansleep()` (sections `WTCANSLP0..`) come from every libmf module you link: the UART TX queue, DebugLink. A stuck veto means no Sleep, ever.

## axradio / easyax5043 engine (`Shared/firmware/axradio`)

The engine is generated by AX-RadioLAB and patched by this project. Files:

- `easyax5043.c` (2,474 lines): the engine state machine, ISR and mode switching
- `config.c`: PHY/MAC register values and constants, **generated**
- `inc/axradio.h`, `inc/easyax5043.h`, `inc/axradio_platform.h`

### API

| Function | Notes |
|---|---|
| `axradio_init()` | Resets the radio, programs the registers, ranges the VCO for each channel. Returns `AXRADIO_ERR_*` |
| `axradio_set_mode(m)` | `AXRADIO_MODE_OFF`, `_DEEPSLEEP`, `_ASYNC_RECEIVE`, `_ASYNC_TRANSMIT`, `_WOR_RECEIVE`, `_ACK_*`, `_SYNC_*`, `_STREAM_*`, `_CW_TRANSMIT`. Coming out of DEEPSLEEP does the full re-programming |
| `axradio_transmit(addr, pkt, len)` | From ASYNC_RECEIVE the engine switches to TX and falls back to RX afterwards (this project relies on that) |
| `axradio_set_channel(n)` | Writes the FREQ set **not** selected by `PLLLOOP` bit 7, then flips the bit |
| `axradio_set_local_address(&mask)` / `axradio_set_default_remote_address(&a)` | 3-byte addresses here |
| `axradio_cansleep()` | Gate for `WTFLAG_CANSLEEP` |
| `axradio_statuschange(st)` | **You implement this.** It is called from the engine (partly in ISR context) with `AXRADIO_STAT_RECEIVE` / `_RECEIVESFD` / `_CHANNELSTATE` / `_TRANSMITSTART` / `_TRANSMITEND` / `_TRANSMITDATA`. For RX: `st->u.rx.pktdata` / `pktlen` / `phy.rssi`; `mac.raw` points into an engine buffer that is only valid during the call |
| `axradio_setup_pincfg1()` / `axradio_setup_pincfg2()` | Radio pin setup: `PALTRADIO = 0`; `PORTR &= 0x3F` (no pull-ups on PR6/PR7) |
| `axradio_commsleepexit()` | Restore the MCU-side radio interface after MCU Sleep |
| `axradio_dbg_snapshot()` | Project addition: logs PWRMODE/POWSTAT/PLLLOOP/PLLRANGINGA/FREQA |

### Project patches in the engine (keep them when regenerating)

- On deep-sleep wake `axradio_set_mode` writes `PLLLOOP = 0x89` before `axradio_set_channel`, so the frequency lands in FREQA. Without it the radio woke on the wrong frequency.
- `axradio_dbg_snapshot()`.
- Diff `easyax5043.c` against a fresh AX-RadioLAB export before replacing it, and re-apply the deltas.

## ShelfKit layers on top

| Module | Role | Key API |
|---|---|---|
| `shelfhw` | board bring-up, clocks, LEDs, log UART, power meter, radio sleep/wake, NFC arm, idle loop | `shelfhw_init`, `shelfhw_poll`, `shelfhw_radio_sleep`, `shelfhw_radio_wake` (retries 8×, returns `AXRADIO_ERR_*`), `shelfhw_led_pulse`, `log_*` |
| `shelflink` | reliable frames POLL/POLL_RSP/DATA/ACK over the engine; retries, dedup, 60 ms response window | `sl_init(node, net, on_rx, on_done)`, `sl_send`, `sl_reply`, `sl_busy` |
| `shelfmsg.h` | application payload opcodes (IMG_*, FW_*, SET_ID, WIPE, FLASH_DUMP, ZCHUNK...) | - |
| `shelfota` | SPI-flash staging of OTA images (sector 0 header "SKFW"), applied by the bootloader | - |
| `shelfid` | tag identity record in SPI flash sector 1 | - |

Protocol details are in `Documentation/wireless-link.md`, OTA in `Documentation/ota-update.md`, identity in
`Documentation/tag-identity.md`. The hub and the server only know addresses and frames.

Configuration switches live in `Vusion/include/shelf_config.h` (`SHELF_*`), in `shelfhw.c`
(`SHELF_FIX_XOSC`, `SHELF_FIX_UART_SLEEP`), and in `sdcc-project.json` `defines` (`SHELF_WAKE_LPXOSC=1`).
They can be overridden per build with `build-all.py --define NAME=VALUE`.
