      When a tag counts as quiet

      Tags check in about every 2 minutes, slow to 5 when idle, and to 10 on a weak link. Keep these above those rates or healthy tags will look quiet.

      Battery

      Tag pages for phones

      Tapping a tag opens <address>/tag/<ID>. This server serves those pages on its own port. To reach them from a phone, forward /tag/ from a reverse proxy to this server, and enter the proxy's address here so the Apps screen shows the right links. Forward nothing else: the rest of this port is this admin page. Leave it empty to show this server's own address.

      USB debugger (AXSDB)

      Leave it empty to use the default install. The Flash screen runs it from that folder with --eraseall and --flashprog.

      Reset and BOOT on GPIO pins

      Wire the board's RESET and BOOT (PB3) to two GPIO pins instead of the serial adapter's RTS and DTR. Then the hub can sit on the Pi's own UART (/dev/serial0, header pins 8 and 10) or on an adapter with only TX, RX and GND. The Reset button, the DTR toggle and serial flashing all drive the pins.

      Use the BCM GPIO number (GPIO17 is header pin 11), not the header pin number. Asserted is low and released is high, just like a USB adapter. Write 27:high for a line that is active high. Leave a field empty to keep that line on the adapter. The server needs python3-libgpiod and the gpio group. When the server stops, the pins float, so a 10 kΩ pull-up to 3.3 V on each wire keeps the hub out of reset.

      Aliases, notes and shelf positions

      A CSV with the columns hex_id, alias, notes, shelf and slot. Importing sets every tag in the file, including tags the hub hasn't heard yet, and a blank cell clears that field.

      AI services

      The Develop screen's agent writes apps with one of these. A key is kept in this server's database (in plain text, next to the rest of ShelfKit's data) and is only ever sent to that service; this page never gets it back, only its last four characters.

      Keys for the web services your apps call (weather, calendars, ...). An app reads one with tag.token("name"), so the key never has to be in its code.
