    Settings

    Saved on this computer with the rest of ShelfKit's data, so every browser that opens the page sees the same values.

    When a tag counts as quiet

    Tags check in about every 2 minutes, slow to 5 when idle, and to 10 on a weak link. Keep these above those rates or healthy tags will look quiet.

    Battery

    A CR2450 starts to fail around 2.5 V. Tags below this value get a red battery reading and show up under Needs attention.

    Serial ports

    The ports are remembered and opened on the Hub screen. Hiding the tag port closes it, but it stays available as a target on the Flash screen. The hub and the tag can't share a port.

    USB debugger (AXSDB)

    Leave it empty to use the default install. The Flash screen runs it from that folder with --eraseall and --flashprog.

    Aliases, notes and shelf positions

    A CSV with the columns hex_id, alias, notes, shelf and slot. Importing sets every tag in the file, including tags the hub hasn't heard yet, and a blank cell clears that field.
