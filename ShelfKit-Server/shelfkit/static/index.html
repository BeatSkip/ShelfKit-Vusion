Tag details

The service image shows the wireless id in large type, the alias, the note above and a black/red patch - so a tag in hand can be matched to this row. Sent wirelessly, like any other image.

Wireless identity

Sent to the tag over the hub port, which stores it in SPI flash and moves its radio address. The tag keeps this id across firmware updates. Leave the field empty to take the next free id.

Firmware update

Sent over the wireless link: the tag stores it in SPI flash, verifies the CRC and resets; the bootloader programs it and starts it. The tag keeps its id. It only listens for a few seconds after each poll, so a transfer can take up to a minute to start.

Forget only drops the server's row; the tag keeps its id and comes back if it polls. Factory reset also tells the tag to erase its flash: it returns with a new random id and no pending firmware.
